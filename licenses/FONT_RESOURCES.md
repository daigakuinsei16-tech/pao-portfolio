# Bundled fonts

The website uses four unmodified OpenType files from the installed URW Base35 font package.

| Website file | Original file | Font family |
| --- | --- | --- |
| `dist/assets/editorial-roman.otf` | `P052-Roman.otf` | P052 |
| `dist/assets/editorial-italic.otf` | `P052-Italic.otf` | P052 |
| `dist/assets/sans-regular.otf` | `NimbusSans-Regular.otf` | Nimbus Sans |
| `dist/assets/sans-bold.otf` | `NimbusSans-Bold.otf` | Nimbus Sans |

The CSS aliases are `Editorial` and `Interface`. The full package notices are preserved in `URW-Base35-COPYRIGHT.txt`.

Upstream font package: https://github.com/ArtifexSoftware/urw-base35-fonts
